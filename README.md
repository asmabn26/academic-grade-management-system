# Academic Grade Management System

Application web de gestion académique développée dans le cadre d'un projet universitaire. Elle centralise le suivi des étudiants, la saisie des notes et les indicateurs pédagogiques.

> Projet académique de démonstration — non destiné à un usage de production.

## Fonctionnalités

- Authentification et espaces utilisateurs.
- Gestion des étudiants, filières et niveaux.
- Saisie et consultation des notes par module.
- Calcul des moyennes et suivi des meilleurs résultats.
- Tableau de bord avec statistiques par classe.
- Génération et consultation de bulletins.

## Technologies

PHP 8 · MySQL/MariaDB · HTML · CSS · JavaScript · Bootstrap · Chart.js

## Démarrage local

1. Installer XAMPP, WampServer ou un environnement PHP/MySQL équivalent.
2. Copier le projet dans le répertoire web local, par exemple `htdocs`.
3. Créer une base MySQL locale et importer le script SQL fourni.
4. Copier `config.example.php` vers `config.php`, puis renseigner uniquement les identifiants de votre base locale.
5. Démarrer Apache et MySQL, puis ouvrir `http://localhost/<nom-du-dossier>`.

## Compétences mobilisées

Application CRUD, modélisation relationnelle, gestion de session, tableaux de bord et génération de documents.
